## 🔹 Sobre o Projeto

Este projeto é uma **apresentação web (slides)** voltada para treinamento ou orientação de colaboradores do PagBank. A apresentação cobre:

- Introdução e contexto da troca de maquininhas  
- Avaliação da necessidade de troca  
- Impactos negativos de trocas desnecessárias  
- Importância de seguir o fluxo correto  
- Oferta Turbo ativa e orientações de comunicação  
- Conclusão e melhores práticas  

A apresentação é **interativa**, permitindo navegar entre os slides e expandir seções para ver mais detalhes.
